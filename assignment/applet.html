Applet Container Execution:
This page hosts the SmartCampusApplet demonstrating the standard Java Applet Lifecycle (init(), start(), paint(), stop(), destroy()) integrated with AWT Delegation Event Model, SHA-256 Hashing, and SQLite persistence.

Applet Viewer Execution Required

Modern web browsers do not run direct NPAPI Java Applets natively. To run this applet directly, execute:

appletviewer applet.html

Or run the standalone desktop GUI application:

run.bat

Command Line Instructions

To compile and execute this system:

# 1. Compile all Java sources
javac -d bin -cp ".;sqlite-jdbc-3.45.1.0.jar" src/com/campus/lostfound/*/*.java

# 2. Run Desktop GUI (AWT Frame)
java -cp "bin;sqlite-jdbc-3.45.1.0.jar" com.campus.lostfound.app.Main

# 3. Run Applet container (Appletviewer)
appletviewer applet.html

# 4. Run Automated Test Suite
java -cp "bin;sqlite-jdbc-3.45.1.0.jar" com.campus.lostfound.test.SmartCampusSystemTest
