Project Title: Smart Campus Lost & Found and Asset Recovery System using Java GUI, File Handling, Serialization, Hashing and JDBC

1. Executive Summary & Assigned Project Role

As the Lead Security & Backend Architect for this Capstone project, I was responsible for designing the overall multi-tier architecture, implementing the SHA-256 cryptographic identity verification subsystem with dynamic salting, and engineering the core desktop GUI with the Delegation Event Model. My implementation directly satisfies Course Outcomes CO4 (AWT components, event handling) and CO5 (SHA-256 hashing, SQLite JDBC CRUD operations, and multi-tier file persistence).

2. Specific Modules, Features & Technical Contributions

A. Cryptographic Authentication Subsystem (HashUtil.java - CO5)

  • Engineered salted SHA-256 identity authentication using java.security.MessageDigest and java.security.SecureRandom to safeguard claimant secret PINs and Student IDs.
  • Generated 16-byte cryptographically secure random salts (32 hex characters) to protect against rainbow table precomputation attacks.
  • Implemented constant-time byte string evaluation (constantTimeEquals) to prevent side-channel timing attacks.

B. AWT GUI Architecture & Delegation Event Model (gui.* - CO4)

  • Constructed the desktop window container (SmartCampusMainFrame) with MenuBar, status tracking, and CardLayout navigation.
  • Developed input validation panels (LostReportPanel, MatchClaimPanel) using GridBagLayout, handling ActionEvent, ItemEvent, and WindowEvent.
  • Integrated modal dialog alerts and real-time state synchronization across all UI components.

C. Business Logic Facade & Algorithmic Matching Engine (service.*)

  • Implemented LostFoundService orchestrating JDBC CRUD operations with ItemDAO, ClaimDAO, AuditDAO, and file stream logging.
  • Formulated the 4-factor heuristic matching engine evaluating category match (40%), keyword overlap (20%), location proximity (20%), and date difference (20%).
  • Created custom domain exceptions (ValidationException, InvalidPINException, DatabaseException).

3. Key Learning Outcomes & SDG Relevance

Technical Growth: Gained deep practical competence in Java desktop event models, constant-time cryptography, object serialization, and SQLite JDBC persistence.
